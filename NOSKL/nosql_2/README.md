# Семантичний пошук наукових статей

## Мета роботи

Метою роботи було ознайомлення з підготовкою текстових даних, створенням векторних представлень наукових статей, роботою з Pinecone, семантичним і гібридним пошуком, а також перенесенням Python-скриптів у середовище Jupyter Notebook.

## Використані технології

- Python;
- Pandas і NumPy;
- Sentence Transformers та модель `allenai/specter2_base`;
- Pinecone;
- BM25 і Reciprocal Rank Fusion;
- Jupyter Notebook у Visual Studio Code.

## Виконання роботи

Спочатку було підготовлено набір наукових статей із заголовками, анотаціями, авторами, роком публікації та категорією. Заголовок і анотація кожної статті об'єднувалися через токен `[SEP]`, після чого для текстів створювалися нормалізовані ембеддинги розмірністю 768.

Отримані вектори та метадані було підготовлено для завантаження в індекс Pinecone. Реалізовано локальне порівняння косинусної подібності, скалярного добутку та евклідової відстані. Для нормалізованих векторів cosine і dot product дають однакове ранжування, а L2 пов'язана з ними формулою:

$$
\|x-y\|^2=2-2\cos(x,y).
$$

Для довгих текстів реалізовано два способи розбиття: фіксовані чанки з перекриттям і семантичні чанки за межами речень. Семантичний спосіб краще зберігає зміст, а перекриття допомагає не втрачати контекст на межах фрагментів.

Для пошуку реалізовано BM25, векторне ранжування та їх об'єднання через Reciprocal Rank Fusion. BM25 краще знаходить точні терміни, абревіатури й імена авторів, а векторний пошук — перефразовані запити та збіги за змістом. RRF поєднує переваги обох методів.

## Опрацювання роботи в Jupyter Notebook

У файлі `notebook_transition.ipynb` послідовно опрацьовано роботу з Python-скриптами в інтерактивному середовищі:

1. Імпортовано бібліотеки та перевірено версії Python, NumPy, Pandas і Matplotlib.
2. Продемонстровано запуск готового скрипту через `%run` та імпорт функцій із пакета `scripts`.
3. Код розділено на окремі клітинки для поетапного виконання й перевірки проміжних результатів.
4. Виведено таблицю статей і побудовано діаграму розподілу записів за категоріями.
5. Використано `assert`, `print` і `%debug` для налагодження коду.
6. Опрацьовано завантаження параметрів із `.env` та використання змінних середовища.
7. Створено простий тест для перевірки функції формування текстів.
8. Використано `%time`, `%timeit` і `cProfile` для оцінювання швидкості виконання.
9. Розглянуто експорт ноутбука назад у Python-скрипт і можливість автоматизації.
10. Описано роботу з Git, вбудованим терміналом і панеллю виводу у VS Code.

Ноутбук дає змогу запускати проєкт частинами, переглядати проміжні дані, будувати візуалізації, тестувати функції та знаходити помилки без повторного запуску всього конвеєра.

## Короткий висновок

У роботі було опрацьовано повний цикл створення пошуку за науковими текстами: підготовку даних, генерацію ембеддингів, індексацію, чанкінг і порівняння BM25, векторного та гібридного пошуку. Jupyter Notebook спростив поетапний запуск, аналіз результатів, тестування й налагодження коду. Гібридний пошук є найуніверсальнішим, оскільки поєднує точність ключових слів BM25 зі здатністю векторного пошуку знаходити документи за змістом.
